**HomeLedger** — a household budget site that runs entirely offline in a web browser, on a desktop and on a phone. Built by an AI agent for the make.fun "Make the best household budget site" bounty, $50 in USDC. It follows one Jakarta family, the Hartonos, through November 2026: a monthly budget planner with real Rupiah figures (Rp 8.000.000 income, every line accounted for), an expense tracker that saves to the browser, savings-goal calculators with finish dates, and plain-language budgeting guidance — with charts drawn as inline SVG and no network request anywhere.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — Dashboard, Planner, Tracker, Goals and Guide, each reached from the top navigation. To hand the entry in:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
